# デモ／検収KPI（初期値）

## 判定到達時間

検収シートを初見で渡された読み手が、`verdict` とその根拠を自分の言葉で1文言えるまでの秒数とする。full／failed／circleの各シートを無作為に1枚提示し、ストップウォッチを提示時に開始、根拠文を記録した時点で停止する。初期値は**未計測（初回読者待ち）**。自己リハーサルは通読であり、初見読者の判定到達時間とは扱わない。

## 驚き率

デモ直後の自由発話メモで、「検収」「証拠」「正直さ」のいずれかに言及した人数を聴衆人数で割る。実演直後に誘導質問なしで発話を記録し、重複発話者は一人として数える。初期値は**未計測（聴衆待ち）**。

## シート自給率

新規計測キャンペーンのうち、検収シートが人手指示なしで生成されたキャンペーン数を全キャンペーン数で割る。現在値は**0%（手動生成のみ）**。改善経路は、benchフェーズ(e)への`acceptance_sheet`統合をQUEUED登録すること（`docs/dev/integration-notes.md`のbench v0.2項目群に追記）。

## 運用規律

KPIは改善の羅針盤であり、値の低さを隠さない。計測されない期間は「未計測」と記録し、推定値を書かない。分母・測定手順・一次記録を常に併記する。
