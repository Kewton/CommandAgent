# デモ／検収KPI（初期値）

## 判定到達時間

正式な開始点を、境界シェルがGate 3で検収シート全文を提示した瞬間へ接続する。
初見読者が、節1の確認済み依頼、節2の`verdict`／assurance、節3の契約check、
節4の機械evidence、節5の停止理由を読み、判定と根拠を自分の言葉で1文言える
までの秒数とする。ストップウォッチはGate 3提示時に開始し、発話文を記録した
時点で停止する。確認card hash、sheet path、秒数、発話文を同じ計測記録へ残す。

初回手順は[`docs/user/first-loop.md`](../user/first-loop.md)、実在する提示形は
`workspace/management/runs/d3c-shakedown-001/boundary-sheets/`にある。D-3cにより、
初見読者へ会話要約ではなく確認identityつき境界シートを渡す正式手順が実行可能に
なった。failedはGate 4の同じ5節、circleは対応する終端シートとして層別に測り、
Gate 3のfull値と混ぜない。

初期値は**未計測（P-3第三者実証の人間到着待ち）**。shakedownや自己リハーサルは
機構検収であり、第三者の判定到達時間には数えない。

## 驚き率

デモ直後の自由発話メモで、「検収」「証拠」「正直さ」のいずれかに言及した人数を聴衆人数で割る。実演直後に誘導質問なしで発話を記録し、重複発話者は一人として数える。初期値は**未計測（聴衆待ち）**。

## シート自給率

新規計測キャンペーンのうち、検収シートが人手指示なしで生成されたキャンペーン数を全キャンペーン数で割る。機構統合済み（bench経由の新規キャンペーンで自動生成）。実測値は**100%（初計測キャンペーン、n=1キャンペーン・6 run、6/6シート生成）**。一次記録は `workspace/management/runs/uat-test0724-cli-001-v3/uat-report.md`。機構完成と実測は同一視しない。

## 運用規律

KPIは改善の羅針盤であり、値の低さを隠さない。計測されない期間は「未計測」と記録し、推定値を書かない。分母・測定手順・一次記録を常に併記する。
