# D-3c 引継メモ：境界対話シェル

検収シートは、単なる終了レポートではなく、対話の各ゲートへ配る機械生成資料である。

- **依頼確定ゲート**：開始前にシート§3「完成の定義」を提示し、束縛された契約チェックを確認する。
- **完了ゲート**：実行後にシート全文を提示し、verdict・assurance・evidence台帳を同じ画面で確認する。
- **失敗ゲート**：§5の平易な停止理由と次の一手（再試行／円環／上位モデル後詰め）を選択肢として提示する。選択は人間が行い、シェルは裁定を代行しない。

設計原則：**対話シェルはシートの各節を対話の各ゲートに配る装置である。**
