# Node failure attribution controls

`positive-cases.json` drives ordered missing hooks, alternate checked paths and
source lengths around both display and executor stream boundaries. The actual
saved #474 command is reused byte-for-byte before the explicit path/comment
transformations. Comments include misleading hook/path text and Japanese/emoji
characters to exercise UTF-16 stack columns.

`negative-cases.json` drives actual unknown, literal-only, printed, swallowed,
removed, different-read, import/export namespace and genuine Test commands.
All uncertain attribute diagnoses stay generic; unchanged classifiers and final
acceptance gates still apply independently of diagnostic precision.

The Rust final-acceptance tests execute these cases through real product
executors, bounded failure reasons, target detection and both actual final repair
prompt layouts. Raw Node output is asserted in temporary workspaces only.
Historical evaluation rows remain valid measurements with their original
diagnostic limitations; these controls do not rewrite or exclude those rows.
